This is a connect 4 AI we made in Prolog for a school project at INSA Lyon.

To play it :

-Install the Prolog terminal on https://www.swi-prolog.org/
-Click 'Consult' on the terminal and select the 'Connect_4_AI.pl' file
- Write 'run.'
- It will ask you how many human players want to play, options are:
    - '0.' -> Ai vs Ai match
    - '1.' -> Human vs Ai match, you can chose your color with 'y.' or 'r.'
    - '2.' -> Human vs Human match
- for each turn type the column where you want to play **followed by a dot**
